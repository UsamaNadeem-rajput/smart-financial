🎯 Project Overview

Smart Financial is a full-stack, web-based Double-Entry Accounting System designed for small to medium businesses, providing professional accounting capabilities without the complexity of enterprise software.

ASSETS = LIABILITIES + EQUITY

All transactions follow the golden rule:

TOTAL DEBITS = TOTAL CREDITS

🔐 Authentication System

📝 Registration Flow

1. User fills signup form
2. Password hashed with bcrypt
3. 6-digit verification code generated
4. Email sent via Nodemailer
5. User redirected to verification page

🔑 Login Options

📧 Email + Password
🔵 Google OAuth 2.0

Session stored in MySQL with secure cookies

🔒 HTTPOnly Cookies
🔐 HTTPS Only
⏰ 24hr Session Expiry
🛡️ CORS Protected

💳 Double-Entry Transaction System

Every transaction affects at least TWO accounts:
One or more accounts are DEBITED, and one or more accounts are CREDITED

Example: Cash Sale of Rs. 10,000

Dr. Cash Account 10,000
Cr. Sales Revenue 10,000

✨ Smart Features

  • Auto-validate Debit = Credit
  • Searchable ledger dropdown
  • Number formatting with commas
  • Success sound on save
  • Auto-balance calculation

🛡️ Security Features

🔐 Password Security

  • Bcrypt hashing (10 salt rounds)
  • Minimum 6 character requirement
  • Never stored in plain text

🍪 Session Security

  • HTTPOnly cookies
  • Secure flag (HTTPS only)
  • SameSite protection
  • MySQL session storage

🌐 API Security

  • CORS configured for specific origins
  • Session verification on all routes
  • 401 for unauthenticated requests
  • Input validation everywhere

📁 File Upload Security

  • File type restrictions
  • 2MB size limit
  • Random filename generation
  • Soft delete for businesses
